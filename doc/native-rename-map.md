# 原生端、channel、JS 與 plugin 改名對照（階段 ③）

本表記錄階段 ③ 的改名，供使用端（如 `nuxt-flutter-app`）與日後遷移對照。**不保留舊名稱**。Dart 公開 API 的改名見 `doc/dart-rename-map.md`。

## 規則

- Channel 前綴：`com.pichillilorenzo/` → `com.github.knighting.cygnus/`；後綴去掉 `flutter_` 與 `inapp`（見下表）。
- JS：全域 `window.flutter_inappwebview` → `window.cygnus`；事件 `flutterInAppWebViewPlatformReady` → `cygnusPlatformReady`；Web 端互通全域 `window.flutter_inappwebview_plugin` → `window.cygnusWeb`；內部變數 `_flutter_inappwebview_*` → `_cygnus_*`。**硬切換，不留舊名稱**。
- Plugin：`InAppWebViewFlutterPlugin` → `CygnusCorePlugin`（Windows `CygnusCorePluginCApi`）；`dartPluginClass` 改為 `Cygnus<平台>WebViewPlatform`。
- 原生類別（Kotlin／Swift／C++）：前綴 `Cygnus`、移除 `InApp`（與 Dart 同一套規則）；小寫識別字 `inApp` → `cygnus`；常數 `IN_APP_` → `CYGNUS_`；C++ 命名空間 `flutter_inappwebview_plugin` → `cygnus_core_plugin`。
- 檔案與目錄：去掉 `in_app_`、`inappwebview` → `webview`；類別檔名跟著類別名。
- 持久化與系統可見：Android 資料庫 `CredentialDatabase.db` → `cygnus_credential_database.db`（首次開啟時自動搬移舊檔）；FileProvider authority `<applicationId>.flutter_inappwebview_android.fileprovider` → `<applicationId>.cygnus_core.fileprovider`；intent key `com.pichillilorenzo.flutter_inappwebview.ChromeCustomTabs.*` → `com.github.knighting.cygnus.ChromeCustomTabs.*`；Linux 環境變數 `FLUTTER_INAPPWEBVIEW_LINUX_DISABLE_GL` → `CYGNUS_LINUX_DISABLE_GL`。
